🚀 MASTER PROMPT FOR LOVABLE AI

Project: LIST YOUR CAR

ROLE & EXPECTATION

You are a world-class product design and engineering AI tasked with designing and building a state-of-the-art, fraud-proof automotive marketplace for Nigeria called List Your Car.

You are expected to deliver:

A complete, production-ready web application

World-class UI/UX

A trust-first product experience

This is not a simple classifieds app.
This is automotive transaction infrastructure.

CORE CONCEPT (NON-NEGOTIABLE)

List Your Car exists to solve one problem:

Buying and selling cars in Nigeria is risky because platforms don’t enforce trust.

The Golden Rule:

ONE CAR → ONE POSTER → VERIFIED SELLERS ONLY

This rule must be enforced technically, visually, and operationally.

PRODUCT PHILOSOPHY

Design and build with these principles:

Trust over traffic

Premium, not flashy

System-enforced honesty

The product should feel:

Secure

Professional

Nigerian-relevant

Investor-grade

TARGET MARKET

Private car owners

Expansion-ready for Africa

FULL FEATURE SET (END-TO-END)
1️⃣ USER ROLES

Buyer

Private Seller

Dealer

Admin (Support, Verification Admin, Super Admin)

2️⃣ AUTHENTICATION & SECURITY

Email + phone signup

OTP verification

Role-based access

2FA for admin

Full audit logs

3️⃣ SELLER VERIFICATION (MANDATORY)

Private Sellers:

Government ID

Selfie verification

Proof of ownership

Dealers:

CAC / business registration

Authorized representative ID

Unverified users cannot post listings.

4️⃣ CAR LISTING SYSTEM (CORE)

Rich car listings with images

Mandatory VIN / chassis number (hidden from public)

VIN uniqueness enforced at database level

No duplicate VINs allowed

One active listing per VIN

Image similarity detection

Admin approval before listing goes live

5️⃣ BUYER EXPERIENCE

Clean browse & search

Filters (price, location, brand, year)

Only verified listings visible

Detailed car pages with trust indicators

In-app messaging (no phone numbers by default)

6️⃣ DEALER EXPERIENCE

Public dealer profile pages

Inventory dashboard

Dealer verification badge

Subscription management

7️⃣ ADMIN DASHBOARD (CRITICAL)

Admins must be able to:

Approve/reject sellers

Approve/reject listings

Monitor VIN registry

Detect fraud patterns

Moderate messages

Handle disputes

Manage escrow transactions

View analytics

Log every admin action

No silent overrides. Every action must be traceable.

8️⃣ ESCROW & PAYMENTS (PHASE 2 – INCLUDE DESIGN)

Design escrow-ready architecture and UI.

Escrow Flow:

Buyer pays → funds held

Inspection occurs

Buyer approves or rejects

Admin can override if needed

Funds released or refunded

Escrow revenue:

2% buyer fee

Optional seller success fee

Inspection margin

Use Nigeria-ready payment logic (Paystack-style escrow simulation).

9️⃣ INSPECTION PARTNER SYSTEM

Inspector onboarding

Inspector dashboard

Job assignment

Inspection report submission (photos, video, checklist)

Inspector ratings & quality control
